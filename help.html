Web Box

Web Box shows a live web page, such as a Tableau dashboard, in a box on an Excel sheet.

  1. Insert → Add-ins → My Add-ins → Web Box.
  2. Paste a link and press Show. For Tableau, a dashboard link, its share link or its embed code all work.
  3. Move and resize the box like a chart. The link is saved in the workbook.
  4. Hover over the www button for back, forward, reload, sign in, zoom, home and open in browser. Use the ⚙ button to change the link.

Signing in

If the page asks you to sign in, use Sign in on the www toolbar, not the page's own sign-in button. A window opens inside Excel: sign in there, and when the dashboard shows in it, close that window. The box reloads signed in.

(The page's own button opens a window that can hang on “You may close this window now” and never signs the box in.)

Only https:// pages can be shown, and the site has to allow being shown inside another page.
